# SwingDemo - Java Class Version Detector

A Swing-based GUI tool for detecting Java class compilation versions inside JAR/ZIP files.

## Features

- Select a JAR/ZIP file via file chooser
- Automatically extracts and scans all `.class` files
- Detects Java compilation version (JDK 1.1 ~ JDK 24)
- Displays results in an interactive table grouped by version
- Helps identify class version conflicts when integrating libraries compiled with different JDK versions
